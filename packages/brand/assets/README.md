# Brand assets

Drop the real logo files here using exactly these names (see `docs/BRAND.md` §4.2).
Until they exist, apps fall back to `placeholder-mark.svg` + the shop name as text.

| File                           | Purpose                                     |
| ------------------------------ | ------------------------------------------- |
| `logo-full.svg`                | Mark + wordmark, horizontal (header)        |
| `logo-full-ar.svg`             | Arabic wordmark variant (optional)          |
| `logo-full-inverse.svg`        | White version for dark/coloured backgrounds |
| `logo-mark.svg`                | Symbol only                                 |
| `favicon.svg`, `favicon.ico`   | Browser tab                                 |
| `apple-touch-icon.png`         | 180×180                                     |
| `icon-192.png`, `icon-512.png` | PWA / Android                               |
| `og-default.png`               | 1200×630 social share image                 |
